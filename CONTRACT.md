# Integration contract
Python 3.11+ standard-library local server + SQLite; vanilla ES modules front end; no npm required.
Root: outputs/scienter-lab. Run python3 -m app.server --port 8765.
Backend owns app/* and tests/test_engine.py. Data agent owns data/* docs/DOCTRINE.md docs/DATA.md scripts/* and tests/test_data.py. Root owns web/* README.md remaining docs and integration.
Taxonomy JSON data/taxonomy.json: {version, factors:[{id,label,group,description,weight,keywords:[str],questions:[str]}], doctrine:{"2":{title,summary,citations:[{label,url}]},"9":same}}.
Factor IDs: insider_trading, cw_reliability, accounting, executive_departures, core_operations, regulatory_action, contemporaneous_knowledge, motive_opportunity, temporal_proximity, magnitude_duration, individual_attribution, opposing_inferences.
Evidence object: {quote, locator, source_url, characterization}; quote exact substring of opinion_text for real cases. User evidence quote substring of input text. Status: present|absent|unknown; strength descriptive only (specific|general|mixed|unknown).
Case data/cases.json: array of {id,name,citation,circuit:"2"|"9",court,date,posture:"motion_to_dismiss"|"appeal_of_dismissal",case_id,defendant_scope:"individual"|"corporate"|"both",outcome:"survived"|"dismissed"|"mixed"|"unresolved",outcome_basis:"scienter"|"other"|"mixed"|"unknown",source_url,opinion_text,summary,synthetic:boolean,review_status:"reviewed"|"needs_review",factors:{factor_id:{status,strength,evidence:[Evidence]}},case_outcome:"unknown", outcome_evidence:Evidence}. Synthetic records must all be plainly fictional and excluded from real statistics.
GET /api/bootstrap => {taxonomy:<taxonomy JSON>,cases:[case],examples:[{id,title,text,circuit,defendant_scope}],matters:[],config:{llm_enabled,corpus_mode},corpus:{real,synthetic,reviewed}}.
POST /api/analyze {text,circuit,defendant_scope,mode:"demo"|"real",posture:"motion_to_dismiss"|"appeal_of_dismissal",cross_circuit:boolean} => {profile:{factors:{id:{status,strength,evidence:[],needs_review:true}},warnings:[],method},results:[{case:<case>,score:0..100,matched_factors:[id],differences:[id],same_circuit:boolean}],stats:{n,survived,dismissed,mixed,unresolved,rate:null|number(0..100),interval:null|[0..100,0..100],suppressed:boolean,reason,unit,mode},doctrine:<doctrine>,warnings:[]}.
POST /api/compare accepts analyze fields + profile and returns same analysis (manual edited profile). POST /api/matters {title,text,circuit,defendant_scope,profile,mode,posture,cross_circuit} => {id,...}; GET /api/matters and GET /api/matters/:id; DELETE /api/matters/:id.
GET /api/cases/:id; GET /api/health.
POST /api/import accepts {cases:[...]} validated same as cases schema, real imports remain needs_review; POST /api/cases/:id/review {reviewer, note} requires all evidence verified. GET /api/export?matter_id=... JSON.
API errors JSON {error:string}; no network by default; optional LLM via env server-side and explicit request field use_llm:true. Default deterministic extraction labeled draft.
